# GEMINI.md — Instruksi Kerja Gemini AI (Proyek MrClean Mac)

Seluruh AI Agent dan model Gemini wajib membaca dan mematuhi tata kelola pada:
- [`Docs/universal-rule.md`](universal-rule.md)
- [`AGENTS.md`](AGENTS.md)

**Aturan Inti:**
1. *No Plan, No Code.*
2. *No Approval, No Code.*
3. *No Evidence, No Completion.*
4. Selalu minta izin Mas Yogi Ario sebelum mengeksekusi kode aplikasi.
5. Jaga branch `main` tetap bersih hanya untuk rilis produksi (tanpa folder `Docs/` dan `changelog/`).
6. Tanyakan cadangan riwayat chat ke `Docs/chat/riwayat<ddmmyyyy>.md` di akhir respon.
